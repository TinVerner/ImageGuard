# Changelog

## 2026-09-29 — RSA PKCS#1 v1.5

### Changed

- цифровая подпись переведена на SHA-256 с `RSASignaturePadding.Pkcs1`;
- значение `algorithm` в `.igsig` изменено на `RSA-SHA256-PKCS1-v1_5`, версия формата осталась 3;
- UI, диагностика и README приведены в соответствие с фактическим padding;
- exact-byte и crypto tests явно проверяют PKCS#1 v1.5.

### Verified

- эксперимент с точной разностью `Delta` показал ошибки извлечения после IDCT и RGB round-trip для `Delta` 5/10/20 и UTF-8 текста;
- постоянный запас `Delta + 25` сохранён для компенсации численного округления и цветового преобразования.

## 2026-09-29 — Simple educational watermark

### Changed

- watermark заменен на понятную цепочку RGB → BT.601 YCbCr → Y → блоки 8×8 → DCT → `C(2,3)`/`C(3,2)` → IDCT → RGB;
- используется одно фиксированное настраиваемое `Delta` со значением 10 по умолчанию;
- текст хранится как 32-битная Big Endian длина и UTF-8 байты, один бит на полный блок;
- `.igsig` обновлен до версии 3 и сохраняет только `watermarkDelta` из параметров извлечения;
- UI защиты и исследования упрощен до одного поля `Delta`;
- BER рассчитывается по сырой последовательности `[длина + UTF-8]`.

### Removed

- прежняя сложная упаковка watermark и ее legacy-совместимость;
- адаптивная сила, изменяемые пары DCT-коэффициентов и расширенный профиль;
- неиспользуемые поля и статусы старого алгоритма в UI, моделях и тестах.

### Verified

- английский и русский UTF-8 текст, `Delta` 5/10/20, недостаточная емкость;
- DCT/IDCT, PNG/JPEG self-check, exact-byte RSA signing, изменение данных, MSE/PSNR/BER;
- независимые ветви проверки RSA и watermark.

## 2026-09-29 — Project rename

- solution переименован в `ImageGuard.slnx`;
- основные проекты переименованы в `ImageGuard` и `ImageGuard.Tests`;
- assembly, root namespace, C# namespaces и WPF `x:Class` унифицированы под именем `ImageGuard`.

## 2026-09-28 — MVP correctness milestone

### Added

- независимые результаты RSA и watermark с отдельными статусами ошибок формата;
- воспроизводимые параметры извлечения watermark в `.igsig`;
- raw-bit BER, MSE (RGB), PSNR и экспорт MSE в CSV;
- определенный progress и отмена защиты, проверки и исследований;
- проверки PNG/JPEG exact-byte signing, JPEG self-check, alpha, краев 8×8, file locks и cancellation;
- поддержка и тест RSA 3072 наряду с RSA 2048.

### Changed

- неверный публичный ключ больше не трактуется как изменение изображения;
- ошибки `.igsig` или RSA-ключа не блокируют независимое извлечение watermark;
- контроль после сохранения требует совпадения извлеченного и исходного текста;
- RSA подписывает только точные байты окончательно сохраненного PNG/JPEG;
- неиспользованные блоки и неполные края не проходят лишний YCbCr round-trip;
- UI показывает MSE, совпадение fingerprint, progress и команды отмены;
- формат результата проверяется на соответствие расширению `.png`/`.jpg`/`.jpeg`.

### Known limitations

- watermark использует последовательные блоки без ECC и повторения;
- надежность watermark после JPEG и геометрических преобразований зависит от параметров и измеряется в Research;
- `.igsig` является служебным sidecar; RSA подписывает изображение, а не JSON-манифест;
- EXIF и другие metadata не гарантируются к сохранению.
